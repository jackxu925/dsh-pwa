## 复现方式

宿主仍是真实的 `dsh web` PWA；在同一会话里把消息区换成一段合成的示例文案（保留应用自己的消息节点、
气泡样式和 meta 行），再只在浏览器里把 `/m/app.js`、`/m/style.css` 换成待测版本（Before 用 main
的静态文件，After 用本分支的静态文件）。这样两边除被测代码外完全一致。

## 关于系统原生菜单

iOS/Android 原生选择菜单由系统绘制在 WebView 之上，Chromium 截图里画不出来。预览条仍停在输入区
上沿，离选区隔着整段对话内容，位于菜单活动带之外；真机（iOS Safari / Android Chrome）最终确认
建议再做一次。

## 功能检查

- 触屏媒体查询命中（`(any-pointer: coarse)` = true）时显示 `.qbar`、隐藏 `.qpill`；鼠标环境相反（桌面浮钮不变）。
- 条的文案与预览来自当前选区；点条打开注解面板、`#quote-full` 是精确片段，保存后引用条出现 1 条，条收起。
- 点 ✕（触摸 `tap`）只清选区并收起条，不触发引用、不打开面板。
- 390×844 深/浅色、320×568 窄屏：条在输入区顶 8px 上，无横向溢出，零 pageerror。
- `node --check web/app.js`、`node test/smoke.mjs` 通过。
