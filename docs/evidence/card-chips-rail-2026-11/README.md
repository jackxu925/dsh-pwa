# 会话卡片右侧竖列对齐 · Before / After

同一真实 PWA 页面壳、390×844、3× 像素密度、浅色主题；两次截图用同一组合成示例会话、同一滚动位置。
**Before** = `origin/main` 的 `web/`（`f30fa02`，即 #29 合并后的状态：时间与工作区 chip 彼此靠右，但右边缘仍停在 ⋯ 按钮左侧）；
**After** = 本分支。
会话标题、摘要和工作区名均为截图用示例（页面壳、`sessionCard()` 渲染函数、卡片 DOM/样式和 ⋯ 菜单都是真实应用，
内容为合成），不含任何真实会话内容。

| `after-390.png` | 本分支：时间、⋯ 圆点、工作区 chip 右边缘都是 362px，形成一条右侧竖列 |

## 测量（390×844，浅色；单位 px）

| 元素 | Before | After |
|---|---|---|
| 右上角时间右边缘 | 323 | 362 |
| 工作区 chip 右边缘 | 323 | 362 |
| ⋯ 圆点右边缘 | 362 | 362 |
| 卡片内横向溢出 | 0 | 0 |
| 空会话卡片高度 | 75 | 104 |

卡片右侧要放得下「时间 / ⋯ / chip」三样，空会话这类短卡会比原来高（75 → 104，最低高度 104）；
有摘要的卡片本来就 ≥121px，高度不变。

## 复现方式

宿主是真实的 `dsh web`（`/m` 静态面 + 真实 API/WS）。用 Playwright 只替换 `/m/style.css`
（Before 取 `origin/main` 的静态文件、After 取本分支），列表在页面内用应用真实的 `sessionCard()`
渲染一组合成会话；页面其它部分（标题栏、连接状态、分段控件、卡片 DOM/样式/交互）都是真实应用。
