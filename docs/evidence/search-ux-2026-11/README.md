# 首页 Universal Search · 清除与空态 Before / After

同一真实 PWA 页面壳、同一组合成会话、390×844、2× 像素密度、浅色主题、同一查询与滚动位置。
**Before** = `origin/main` 的 `web/`（`69fda0a`，PR #34 合入后的基线）；**After** = 本分支（`v1.22.2`）。
页面壳、搜索渲染、卡片 DOM 都是应用自己的代码；会话与消息内容是合成示例，不含真实会话。
“宿主”由本地 stub 复刻（`session/list`、`pwa.search`、`/api/remote.mux`），没有连接真实 `dsh web`。

场景：

- 搜索「缓存」：标题/路径 0 命中，消息内容 3 条。这是用户反馈的场景。
- 搜索「量子纠缠」：所有来源 0 命中。

## 实测

- 清除 ✕：任何非空输入（含仅空格）出现；点击清空且焦点留在输入框；Esc 同效；Tab 可聚焦、Enter 触发；清空后分段控件与完整列表回来，`aria-hidden` / `tabindex` 同步。
- 范围摘要：仅消息命中时显「标题/路径 0 · 消息内容 3」，不再出现空状态；标题/消息都命中时为「会话」「消息内容」两段；全部 0 时让位给轻量空状态；1 个字时提示「再输入 1 个字可搜索消息内容」，空状态只声明搜过标题与路径。
- 搜索时隐藏列表分段控件；清空后恢复。自动化页里搜索再清空，分段控件和范围摘要都能正确回位。
- 0 命中空状态没有「清除搜索」主按钮；清空动作只在输入框的 ✕ 里。
- 索引建立中：已有消息结果照常展示，底部一行「正在建立消息索引 2/4…」；内容搜索失败：范围摘要显示「消息内容 暂不可用」，标题结果不受影响。
- 快速改词时旧响应由 `seq` 丢弃，不会把上一个词的命中画到新词下面。
- 390×844 浅 / 深色、320×568 浅色：无横向溢出，零 pageerror；`node --check web/app.js`、`node test/smoke.mjs` 通过。

## 限制

- 截图来自 Chromium 手机模拟，未在 iPhone / Android 真机复采；原生键盘弹出时 ✕ 的焦点保持未在真机截图中验证（代码在 click 手势内重新 `focus()`，与现有输入框行为一致）。
- `pwa.search` 由 stub 返回合成命中；真实本地索引的行为仍由 `test/search.mjs` 覆盖。
